# Register a New Duple

1. Copy `_template.yaml` → rename to `{your_duple_id}.yaml`
2. Fill in every field (see `thay.yaml` as a real example)
3. Commit and push
4. Notify the Duply team — we'll pull, provision your schema, generate your `duples/{duple_id}/` folder, and push it back

**Do not include LINE tokens in this file.** Send `LINE_CHANNEL_ACCESS_TOKEN` and `LINE_CHANNEL_SECRET` to the Duply team via a separate secure channel.
